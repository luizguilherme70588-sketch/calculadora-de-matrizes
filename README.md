Calculadora de Matrizes
Descrição

Projeto desenvolvido em linguagem C para realizar operações matemáticas com matrizes.

Funcionalidades
Cadastro de duas matrizes.
Exibição das matrizes.
Adição de matrizes.
Subtração de matrizes.
Multiplicação de matrizes.
Inversão de matrizes.
Divisão de matrizes.
Linguagem utilizada
Linguagem C.
Arquivos do projeto
main.c: menu principal do programa.
matrizes.c: implementação das operações matemáticas.
matrizes.h: declaração das estruturas e funções.
Autor

Projeto acadêmico desenvolvido para atividade de programação em linguagem C.
